How it works

  1. 1
    Open your HTML Run the CLI on a slide, proposal, or landing page folder.
  2. 2
    Comment on the page Click an element or select text and say what should change.
  3. 3
    Your agent fixes it Each comment is sent immediately. The agent fixes, then watches for the next one.
↻
2 · Comment → 3 · Fix → Review

Repeat steps 2 & 3 until you're happy with everything.

Start now

Pick a command, run it in your project folder, and open the preview.

npx comment-to-fix
pnpm dlx comment-to-fix ./index.html --open
bunx comment-to-fix proposal.html --open

Defaults to ./index.html in the current directory.

Every comment has a state

Each marker on the page shows exactly where your comment is in the loop, so you always know what the agent is doing.

  1. Annotating You picked an element and you're typing what should change.
  2. 1
    Sent The comment is captured and queued in the agent's inbox.
  3. Fixing The agent has the comment and is editing your files right now.
  4. Ready The fix landed. Click the green marker to reload and see the change.
  5. Dismissed You hid the marker. It stays in history so you can jump back anytime.

Agent skill

Install the skill, then run /comment-to-fix in Cursor, Claude Code, or Codex. Your agent starts the preview, watches for comments, fixes each one, and keeps watching until you say stop. 

npx skills add ralfboltshauser/comment-to-fix
